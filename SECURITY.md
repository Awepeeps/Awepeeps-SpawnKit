# Security policy

This repository holds a public Minecraft server plugin. Please report suspected
security issues **privately**, not in a public issue, discussion, or comment:

- Use GitHub's **private vulnerability reporting** for this repository
  (**Security** tab → **Report a vulnerability**). There is no separate
  maintainer email channel.

When reporting, include:

- the plugin version and the exact jar name if you have it,
- the Paper and Java versions involved, and
- a minimal, generic reproduction (steps someone else can follow).

Keep reports generic: do not paste real hostnames, IPs, server names, player
names, world coordinates, seeds, logs, or config dumps.

The deployed test build is pinned (source commit + jar SHA-256) in a private
repository; that is not a reporting channel and details from it are not needed
for a report here.
